## Portfolio design

The site uses a responsive dark developer-portfolio layout with a blue accent palette, custom hero portrait, project cards, skills, experience, education, certifications and contact links.

The site is static HTML, CSS and JavaScript. It does not require a build step.

## Run locally

1. Clone this repository.
2. Open `index.html` in a browser or serve the folder with a local static-file server.
3. Keep `index.html`, `style.css`, `script.js`, `assets/profile.jpg` and `resume.pdf` at their referenced paths.
